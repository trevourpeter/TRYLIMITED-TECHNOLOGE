# Keyboard Shortcuts - Quick Start Guide

## 🎯 What's New?

Your Stationery POS system now supports **fully customizable keyboard shortcuts**! Each user can create their own shortcuts tailored to their workflow.

## 🚀 Quick Example

**Scenario:** You want to make a sale using `Space + S` instead of the default `Ctrl + Shift + S`.

### Step-by-Step:

1. **Login** to your account (admin@stationery.com or cashier@stationery.com)

2. **Go to Settings**
   - Click "Settings" in the sidebar
   - Scroll to see the "Keyboard Shortcuts" section at the top

3. **Edit the Quick Sale Shortcut**
   - Find "Quick Sale" in the Point of Sale tab
   - Click the "Edit" button
   - Click "Start Recording"
   - Press `Space` then `S` together
   - Click "Save Shortcut"

4. **Test It!**
   - Go to any page
   - Press `Space + S`
   - The POS interface should open instantly! 🎉

## 📋 Default Shortcuts

### For All Users
- `Ctrl + F` - Focus Search
- `Ctrl + B` - Open Barcode Scanner
- `Ctrl + Enter` - Complete Sale
- `Ctrl + Delete` - Clear Cart

### For Admins Only
- `Ctrl + N` - Add New Product
- `Ctrl + Shift + R` - View Reports
- `Ctrl + Shift + U` - Cash Up

## 💡 Pro Tips

### 1. **Use the Help Dialog**
   - Click the "Shortcuts" button in the sidebar footer
   - See all your current shortcuts in one place
   - No need to memorize everything!

### 2. **Per-User Customization**
   ```
   Admin account: Can set Ctrl + Shift + S for sales
   Cashier account: Can set Space + S for sales
   Both work independently! ✨
   ```

### 3. **Best Practices**
   - ✅ Use modifiers (Ctrl, Alt, Shift) to avoid conflicts
   - ✅ Keep related actions in similar patterns (e.g., Space + S, Space + C, Space + B)
   - ✅ Avoid common browser shortcuts (Ctrl + T, Ctrl + W, etc.)
   - ✅ Test your shortcuts after setting them

### 4. **Easy Reset**
   - Made a mistake? Click "Reset All" in settings
   - All shortcuts will return to defaults
   - You can start fresh anytime!

## 🔧 Troubleshooting

### Shortcut Not Working?
1. Make sure you're not typing in an input field
2. Check if the shortcut is correctly saved in Settings
3. Look for conflict warnings when setting shortcuts
4. Try the "Shortcuts" help dialog to see current bindings

### Conflict Detected?
- The system prevents duplicate shortcuts
- If you see an error, the shortcut is already used
- Choose a different key combination
- Or edit the conflicting shortcut first

### Lost Your Custom Shortcuts?
- Shortcuts are saved per user account
- Make sure you're logged in to the right account
- Each user ID has separate shortcut settings
